API Reference

Complete reference for all TechDocs API endpoints, parameters, and response formats

OAuth 2.0 Authentication

TechDocs supports OAuth 2.0 for secure authentication and authorization.

POST /oauth/authorize

Initiate the OAuth authorization flow

Request Parameters

Parameter Type Required Description
client_id string required Your application's client ID
response_type string required Must be code
redirect_uri string required URL to redirect after authorization
scope string optional Requested permissions (space-separated)

Example Request

const params = new URLSearchParams({
  client_id: 'your-client-id',
  response_type: 'code',
  redirect_uri: 'https://your-app.com/callback',
  scope: 'read write'
});

window.location.href = `https://api.techdocs.com/oauth/authorize?${params}`;
POST /oauth/token

Exchange authorization code for access token

Request Parameters

Parameter Type Required Description
grant_type string required Must be authorization_code
client_id string required Your application's client ID
client_secret string required Your application's client secret
code string required Authorization code from callback

Example Response

{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "refresh_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "scope": "read write"
}

API Key Authentication

For simpler use cases, you can use API key authentication instead of OAuth.

GET /api/v1/account

Get account information using API key authentication

Headers

Header Type Required Description
Authorization string required API key in format: Bearer your-api-key

Example Request

const response = await fetch('https://api.techdocs.com/v1/account', {
  headers: {
    'Authorization': 'Bearer your-api-key-here'
  }
});

const account = await response.json();
console.log(account);
