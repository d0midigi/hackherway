Introduction to DOM

The Document Object Model (DOM) is a programming interface for web documents. It represents the page so that programs can change the document structure, style, and content. The DOM represents the document as nodes and objects; this way, programming languages can interact with the page. 

// The document object is the main entry point to the DOM
console.log(document.title); // Outputs the document title
console.log(document.URL);   // Outputs the document URL

DOM Selectors

Basic Selectors

Methods to select elements from the DOM:

Method Description
getElementById() Selects an element by its ID attribute
getElementsByClassName() Returns a live HTMLCollection of elements with the given class name
getElementsByTagName() Returns a live HTMLCollection of elements with the given tag name
getElementsByName() Returns a live NodeList of elements with the given name attribute 
// Select element by ID
const header = document.getElementById('header');

// Select elements by class name
const buttons = document.getElementsByClassName('btn');

// Select elements by tag name
const paragraphs = document.getElementsByTagName('p');

// Select elements by name attribute
const radioButtons = document.getElementsByName('gender');

Query Selectors

Modern methods to select elements using CSS selectors:

Method Description
querySelector() Returns the first element that matches the CSS selector
querySelectorAll() Returns a static NodeList of all elements that match the CSS selector 
// Select the first element that matches a CSS selector
const firstButton = document.querySelector('button');

// Select the first element with class 'primary'
const primaryButton = document.querySelector('.primary');

// Select element with id 'main'
const main = document.querySelector('#main');

// Select all paragraphs inside a div with class 'content'
const contentParagraphs = document.querySelectorAll('div.content p');

// Select all elements with a specific attribute
const externalLinks = document.querySelectorAll('a[target="_blank"]');

DOM Traversal

Parent Navigation

Methods and properties to navigate to parent elements:

Property Description
parentNode Returns the parent node of an element
parentElement Returns the parent element of an element
closest() Returns the closest ancestor that matches a selector 
// Get parent node
const parent = element.parentNode;

// Get parent element
const parentEl = element.parentElement;

// Find closest ancestor matching a selector
const closestForm = element.closest('form');

Sibling Navigation

Properties to navigate to sibling elements:

Property Description
nextSibling Returns the next sibling node
previousSibling Returns the previous sibling node
nextElementSibling Returns the next sibling element
previousElementSibling Returns the previous sibling element 
// Get next sibling node (including text nodes)
const nextNode = element.nextSibling;

// Get previous sibling node (including text nodes)
const prevNode = element.previousSibling;

// Get next sibling element (excluding text nodes)
const nextElement = element.nextElementSibling;

// Get previous sibling element (excluding text nodes)
const prevElement = element.previousElementSibling;

Child Navigation

Properties and methods to navigate to child elements:

Property/Method Description
childNodes Returns a live NodeList of all child nodes
children Returns a live HTMLCollection of all child elements
firstChild Returns the first child node
lastChild Returns the last child node
firstElementChild Returns the first child element
lastElementChild Returns the last child element 
// Get all child nodes (including text nodes)
const allChildNodes = element.childNodes;

// Get all child elements (excluding text nodes)
const allChildren = element.children;

// Get first child node (including text nodes)
const firstNode = element.firstChild;

// Get last child node (including text nodes)
const lastNode = element.lastChild;

// Get first child element (excluding text nodes)
const firstChildEl = element.firstElementChild;

// Get last child element (excluding text nodes)
const lastChildEl = element.lastElementChild;

DOM Manipulation

Creating Elements

Methods to create DOM elements:

Method Description
createElement() Creates a new element node
createTextNode() Creates a new text node
createDocumentFragment() Creates a document fragment node 
// Create a new element
const newDiv = document.createElement('div');

// Create a text node
const newText = document.createTextNode('Hello World');

// Create a document fragment (for efficient DOM insertions)
const fragment = document.createDocumentFragment();

Modifying Elements

Properties and methods to modify DOM elements:

Property/Method Description
innerHTML Gets or sets the HTML content of an element
textContent Gets or sets the text content of an element and all its descendants
innerText Gets or sets the visible text content of an element
outerHTML Gets or sets the HTML including the element itself 
// Set HTML content (parses HTML)
element.innerHTML = 'New content';

// Set text content (no HTML parsing)
element.textContent = 'New text content';

// Set visible text content
element.innerText = 'New visible text';

// Replace the element and its content
element.outerHTML = '
Replacement
';

Inserting Elements

Methods to insert elements into the DOM:

Method Description
appendChild() Adds a node as the last child of a node
insertBefore() Inserts a node before a reference node as a child of a specified parent node
append() Inserts nodes or text after the last child of the element
prepend() Inserts nodes or text before the first child of the element
after() Inserts nodes or text after the element
before() Inserts nodes or text before the element
insertAdjacentElement() Inserts an element at a specified position relative to the element
insertAdjacentHTML() Parses HTML and inserts it at a specified position relative to the element
insertAdjacentText() Inserts text at a specified position relative to the element 
// Append a child to an element
parentElement.appendChild(newElement);

// Insert before a specific child
parentElement.insertBefore(newElement, referenceElement);

// Append multiple nodes and strings (newer method)
element.append(textNode, newElement, 'Text string');

// Prepend multiple nodes and strings (newer method)
element.prepend('First child', newElement);

// Insert after element (newer method)
element.after(newElement, 'Text after');

// Insert before element (newer method)
element.before('Text before', newElement);

// Insert at specific positions
element.insertAdjacentElement('beforebegin', newElement); // Before the element
element.insertAdjacentElement('afterbegin', newElement);  // Inside, before first child
element.insertAdjacentElement('beforeend', newElement);   // Inside, after last child
element.insertAdjacentElement('afterend', newElement);    // After the element

// Insert HTML at specific positions
element.insertAdjacentHTML('beforeend', '
New HTML
');

Removing Elements

Methods to remove elements from the DOM:

Method Description
removeChild() Removes a child node from the DOM and returns the removed node
remove() Removes the element from the DOM
replaceChild() Replaces a child node with a new node
replaceWith() Replaces the element with new nodes or strings 
// Remove a child element (older method)
const removedElement = parentElement.removeChild(childElement);

// Remove element directly (newer method)
element.remove();

// Replace a child node (older method)
parentElement.replaceChild(newElement, oldElement);

// Replace element with new content (newer method)
element.replaceWith(newElement, 'Text content');

Attributes & Properties

Working with Attributes

Methods to manipulate HTML attributes:

Method Description
getAttribute() Gets the value of an attribute
setAttribute() Sets the value of an attribute
removeAttribute() Removes an attribute
hasAttribute() Checks if an element has a specified attribute
attributes Returns a live collection of all attributes
dataset Access to all data-* attributes 
// Get attribute value
const href = element.getAttribute('href');

// Set attribute value
element.setAttribute('title', 'New tooltip text');

// Remove attribute
element.removeAttribute('disabled');

// Check if attribute exists
if (element.hasAttribute('data-id')) {
    // Do something
}

// Access all attributes
for (const attr of element.attributes) {
    console.log(`${attr.name}: ${attr.value}`);
}

// Working with data attributes
// 
...

Working with Properties

Common DOM element properties:

Property Description
id Gets or sets the element's id
className Gets or sets the class attribute
classList Returns a DOMTokenList with the classes
value Gets or sets the value of form elements
checked Gets or sets the checked state of checkbox/radio
disabled Gets or sets the disabled state 
// Manipulating element properties
element.id = 'newId';
element.className = 'btn primary';
element.hidden = true;

// Form element properties
const input = document.querySelector('input[type="text"]');
input.value = 'New value';
input.placeholder = 'Enter text...';

// Checkbox/radio properties
const checkbox = document.querySelector('input[type="checkbox"]');
checkbox.checked = true;
checkbox.disabled = false;

// Select element
const select = document.querySelector('select');
select.selectedIndex = 2;
const selectedValue = select.value;
const selectedOption = select.options[select.selectedIndex];

Styles & Classes

Manipulating Classes

Methods to work with CSS classes:

Method Description
classList.add() Adds one or more classes
classList.remove() Removes one or more classes
classList.toggle() Toggles a class (adds if absent, removes if present)
classList.contains() Checks if an element has a specific class
classList.replace() Replaces one class with another 
// Add classes
element.classList.add('active', 'visible');

// Remove classes
element.classList.remove('hidden', 'disabled');

// Toggle class (second parameter forces state if provided)
element.classList.toggle('expanded'); // Toggle
element.classList.toggle('selected', isSelected); // Add if isSelected is true

// Check if element has a class
if (element.classList.contains('active')) {
    // Element has 'active' class
}

// Replace class
element.classList.replace('btn-default', 'btn-primary');

Manipulating Styles

Methods and properties to manipulate CSS styles:

Property/Method Description
style Object to get or set inline CSS properties
getComputedStyle() Returns the computed style of an element
style.setProperty() Sets a CSS custom property on an element
style.getPropertyValue() Gets the value of a CSS property
style.removeProperty() Removes a CSS property 
// Set individual inline styles
element.style.color = 'blue';
element.style.backgroundColor = 'yellow'; // Note: camelCase for CSS properties
element.style.fontSize = '16px';

// Set multiple styles at once
Object.assign(element.style, {
    color: 'white',
    backgroundColor: 'black',
    padding: '10px'
});

// Get computed styles (actual rendered styles including CSS rules)
const computedStyle = window.getComputedStyle(element);
const fontSize = computedStyle.fontSize;
const display = computedStyle.getPropertyValue('display');

// CSS custom properties (variables)
element.style.setProperty('--main-color', '#5D5CDE');
const mainColor = element.style.getPropertyValue('--main-color');
element.style.removeProperty('--main-color');

DOM Events

Event Listeners

Methods to handle DOM events:

Method Description
addEventListener() Attaches an event handler to an element
removeEventListener() Removes an event handler
dispatchEvent() Dispatches an event manually 
// Add event listener
element.addEventListener('click', function(event) {
    console.log('Element clicked!');
});

// Using an arrow function
element.addEventListener('mouseover', (event) => {
    console.log('Mouse over!');
});

// With options object
element.addEventListener('scroll', handleScroll, { 
    passive: true,    // Improves scrolling performance
    once: true,       // Auto-removes listener after first call
    capture: false    // Event phase
});

// Named function for event handling (allows removal)
function handleClick(event) {
    console.log('Clicked!');
}
element.addEventListener('click', handleClick);

// Remove event listener
element.removeEventListener('click', handleClick);

// Create and dispatch custom event
const customEvent = new CustomEvent('myEvent', {
    bubbles: true,
    detail: { key: 'value' }
});
element.dispatchEvent(customEvent);

Event Object

Properties and methods of the event object:

Property/Method Description
target Element that triggered the event
currentTarget Element that the event listener is attached to
preventDefault() Prevents the default action
stopPropagation() Stops the event from bubbling/capturing
type Type of event (e.g., "click")
eventPhase Current phase of event flow (capturing=1, target=2, bubbling=3)
timeStamp Time when the event was created
clientX/clientY Mouse position relative to the viewport (mouse events)
key/code Key information (keyboard events) 
// Working with the event object
element.addEventListener('click', (event) => {
    // Prevent default behavior (e.g., for links)
    event.preventDefault();
    
    // Stop event propagation
    event.stopPropagation();
    
    // Get the element that was actually clicked
    const clickedElement = event.target;
    
    // The element the listener is attached to
    const listenerElement = event.currentTarget;
    
    // For mouse events, get coordinates
    const x = event.clientX;
    const y = event.clientY;
    
    // Get key information for keyboard events
    document.addEventListener('keydown', (event) => {
        console.log(`Key pressed: ${event.key}`);
        console.log(`Key code: ${event.code}`);
        
        // Check for specific keys
        if (event.key === 'Enter') {
            // Do something
        }
        
        // Check for modifier keys
        if (event.ctrlKey && event.key === 's') {
            event.preventDefault(); // Prevent browser save dialog
            // Handle Ctrl+S
        }
    });
});

Event Delegation

Pattern to handle events for multiple elements with a single listener:

// Event delegation pattern
// Instead of adding event listeners to multiple buttons:
document.getElementById('container').addEventListener('click', (event) => {
    // Check if the clicked element is a button
    if (event.target.matches('button')) {
        // Handle button click
        console.log('Button clicked:', event.target.textContent);
        
        // Get data attributes
        const id = event.target.dataset.id;
        const action = event.target.dataset.action;
        
        // Perform actions based on button attributes
        if (action === 'edit') {
            editItem(id);
        } else if (action === 'delete') {
            deleteItem(id);
        }
    }
});

Advantages of event delegation:

  • Memory-efficient for large number of elements
  • Works for dynamically added elements
  • Less code to manage
  • No need to add/remove listeners when elements are added/removed
