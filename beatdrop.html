Dropbox Shared Link

Paste a Dropbox shared link to stream your audio file directly. The link must allow anyone with the link to view/download.

  1. Go to Dropbox, right-click your audio file
  2. Select Share → Copy link
  3. Paste the link below (it should look like: https://www.dropbox.com/s/xxxxx/file.mp3?dl=0)
Tip: Make sure your Dropbox link ends with ?dl=0 or ?dl=1. The platform will automatically convert it for streaming. For best results, use direct MP3 or WAV links.
